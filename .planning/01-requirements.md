# 요구사항 정의 (MoSCoW)

## Must Have — 반드시 있어야 함

| ID | 기능 | 설명 |
|---|---|---|
| M-01 | 채팅형 지출 입력 | 자연어 한 줄로 지출/수입 기록 |
| M-02 | 자동 날짜 파싱 | "어제", "3일전", "2025-05-10" 등 자동 인식 |
| M-03 | 자동 금액 파싱 | "6000원", "6000", "6k" 등 자동 인식 |
| M-04 | 카테고리 자동 분류 | 키워드 기반으로 식비/교통/카페 등 자동 분류 |
| M-05 | 지출/수입 내역 목록 | 날짜별 내역 리스트 조회 |
| M-06 | 월별 합계 요약 | 이번 달 총 지출 / 총 수입 / 잔액 |
| M-07 | 로컬 데이터 저장 | 앱 재시작 후에도 데이터 유지 (SQLite) |

## Should Have — 있으면 좋음

| ID | 기능 | 설명 |
|---|---|---|
| S-01 | 카테고리별 차트 | 도넛 차트로 카테고리 비중 시각화 |
| S-02 | 일별 지출 막대 차트 | 한 달간 일별 지출 흐름 |
| S-03 | 저축 목표 설정 | 목표 이름, 목표 금액, 기간 설정 |
| S-04 | 저축 진행률 | 저축 목표 대비 현재 달성률 표시 |
| S-05 | 내역 수정/삭제 | 잘못 입력한 내역 수정 또는 삭제 |
| S-06 | 카테고리 수동 변경 | 자동 분류가 틀렸을 때 직접 수정 |

## Could Have — 여유가 있으면

| ID | 기능 | 설명 |
|---|---|---|
| C-01 | 모의 주식 투자 | 가상 자금으로 실제 주가 기반 투자 시뮬레이션 |
| C-02 | 예산 설정 | 카테고리별 월 예산 설정 및 초과 알림 |
| C-03 | 반복 지출 등록 | 월세, 구독료 등 정기 지출 자동 등록 |
| C-04 | 데이터 내보내기 | CSV로 내역 내보내기 |
| C-05 | 다크모드 | UI 테마 전환 |

## Won't Have — 이번 버전에서 제외

| ID | 기능 | 이유 |
|---|---|---|
| W-01 | 은행 계좌 연동 | Open Banking API 인증 절차 복잡, 6주 범위 초과 |
| W-02 | 소셜 로그인 | 서버 불필요한 로컬 앱 방향과 맞지 않음 |
| W-03 | 다중 사용자 / 공유 | 개인용 앱 컨셉과 충돌 |
| W-04 | AI 소비 코칭 | LLM API 비용 및 복잡도, 추후 버전에서 고려 |

## 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 성능 | 채팅 입력 후 0.5초 이내 기록 완료 |
| 플랫폼 | Android 우선, iOS 지원 |
| 오프라인 | 인터넷 없이도 기록/조회 가능 |
| 데이터 | 로컬 SQLite, 앱 삭제 전까지 영구 보존 |
