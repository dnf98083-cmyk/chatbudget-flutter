# ChatBudget 설치 & 실행 가이드

설치 없이 웹 링크로 바로 쓸 수 있습니다. 스마트폰 홈 화면에 추가하면 일반 앱처럼 사용 가능합니다.

---

## 방법 1 — 웹 브라우저로 바로 실행 (PC / 스마트폰 공통)

**링크**: https://dnf98083-cmyk.github.io/chatbudget-flutter/app/

- Chrome 브라우저 권장
- 첫 로딩 10~20초 소요 (이후에는 빠름)
- 별도 설치 불필요

---

## 방법 2 — 스마트폰 홈 화면에 추가 (앱처럼 사용)

### Android (크롬)

1. 크롬에서 앱 링크 접속
2. 주소창 오른쪽 `⋮` 메뉴 탭
3. **"앱 설치"** 또는 **"홈 화면에 추가"** 선택
4. 이름 확인 후 **"추가"** 탭
5. 홈 화면에서 ChatBudget 아이콘으로 실행

### iOS (사파리)

1. 사파리에서 앱 링크 접속
2. 하단 **공유 버튼** (□↑) 탭
3. **"홈 화면에 추가"** 선택
4. 이름 확인 후 **"추가"** 탭
5. 홈 화면에서 ChatBudget 아이콘으로 실행

> 홈 화면 추가 후에는 전체 화면으로 실행되어 일반 앱과 동일하게 사용 가능합니다.

---

## 사용 방법 (시작하기)

1. 앱 실행 → 회원가입 (닉네임 + 비밀번호)
2. 채팅창에 지출 한 줄 입력:
   - `"스타벅스 6000원"` → 카페, 6,000원 자동 기록
   - `"어제 택시 12000"` → 교통, 어제 날짜로 기록
   - `"월급 250만원"` → 수입, 2,500,000원 기록
3. 하단 메뉴에서 **내역 / 통계 / 저축** 탭 확인
