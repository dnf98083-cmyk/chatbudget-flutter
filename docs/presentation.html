슬라이드 1 / 12
【비전 — 25초】
안녕하세요. 저는 챗버짓(ChatBudget)을 개발했습니다. 비전은 단 하나입니다. "매일 쓰는 채팅으로 가계부를 대체한다." 채팅창에 "스타벅스 6000원" 한 줄만 입력하면, 에이아이(AI)가 자동으로 가계부를 기록합니다. 설치 없이, 이 링크 하나로 지금 바로 사용할 수 있습니다.
【문제 정의 — 25초】
가계부 앱, 설치해보신 분 계시죠? 근데 지금도 쓰고 계신 분은요? 대부분 설치만 하고 결국 안 씁니다. 이유는 간단합니다. 카테고리 고르고, 날짜 탭하고, 금액 입력하는 세 단계가 매번 귀찮기 때문입니다. 챗버짓은 이 세 단계를 채팅 한 줄로 대체했습니다.
【라이브 데모 — 30초】
지금 앱을 직접 열겠습니다. (앱 미리 켜두기 ★)
① "스타벅스 아메리카노 6000" 입력 → 제미나이(Gemini) 에이아이가 카페, 6천원으로 자동 분류.
② "어제 택시 12000원" → 날짜도 어제로 자동 설정.
③ "헬스장 8만원" → 에이아이가 "헬스장" 새 카테고리를 직접 만들어 추가.
이게 챗버짓입니다. (내역·통계 화면으로 전환해서 보여주기)
【WBS + 기술스택 — 20초】
더블유비에스(WBS) 기준으로 30개 항목 중 29개를 완료, 97%를 달성했습니다. 기술 스택은 플러터(Flutter)로 단일 코드에서 웹과 안드로이드를 동시 지원, 에스큐라이트(SQLite)로 오프라인 저장, 제미나이(Gemini) 에이아이로 자연어 파싱을 구현했습니다.
【구현 방법 — 20초】
구현은 4레이어로 역할을 분리했습니다. 화면만 담당하는 프레젠테이션(Presentation), 자연어 파싱인 도메인(Domain), 디비(DB)와 에이아이 호출인 데이터(Data), 에스큐라이트 파일인 인프라스트럭처(Infrastructure)입니다. 에이아이 파싱 실패 시 룰 베이스드(rule-based) 파서가 자동 폴백되어 항상 결과를 보장합니다.
【활용 방안 — 15초】
챗버짓은 개인 가계부 기록, 월별 지출 분석, 저축 목표 관리 세 가지로 활용합니다. 설치 없이 웹 링크 하나로 쓸 수 있어서, 기록 문턱을 없애고 지속 가능한 가계부 습관을 만드는 게 핵심 가치입니다.
【아키텍처 — 20초】
앱 구조를 설명하겠습니다. 4레이어 아키텍처로 나눴습니다. 프레젠테이션(Presentation)은 화면, 도메인(Domain)은 자연어 파싱 비즈니스 로직, 데이터(Data)는 에스큐라이트(SQLite) 크루드(CRUD)와 에이아이 서비스, 인프라스트럭처(Infrastructure)는 실제 로컬 파일입니다. 트랜잭션파서(TransactionParser)를 유아이(UI)와 분리해서 독립 단위 테스트가 가능합니다.
【개발환경 + 빌드/배포 — 20초】
개발 환경은 플러터 에스디케이(Flutter SDK) 설치 후, 깃 클론(git clone) → 플러터 펍 겟(flutter pub get) → 플러터 런(flutter run) 세 줄이면 됩니다. 빌드는 소스코드를 실행 파일로 변환하는 것이고, 배포는 그 파일을 서버에 올려 사용자가 접근하게 하는 것입니다. 플러터 빌드 웹(flutter build web) 후 깃 푸시(git push)하면 깃허브 페이지스(GitHub Pages)가 자동 서빙합니다.
【구현 시행착오 & 성능 최적화 — 20초】
가장 큰 시행착오는 플러터(Flutter) 웹에서 에스큐라이트(SQLite)가 기본 지원이 안 된다는 점이었습니다. sqflite_ffi_web(스큐플라이트 에프에프아이 웹)과 OPFS(오피에프에스)로 해결했습니다. 또한 에이아이(AI) 키 노출 위험은 다트 디파인(--dart-define)으로 해결하고, 디비(DB) 싱글톤 패턴과 밸류노티파이어(ValueNotifier)로 성능도 최적화했습니다.
【테스트 + 코드품질 — 20초】
단위 테스트는 플러터 테스트(flutter test)로 트랜잭션파서(TransactionParser) 3개 케이스를 검증합니다. 모두 통과했습니다. 통합 테스트는 채팅 입력부터 에스큐라이트(SQLite) 저장까지 실제 앱 실행으로 전 흐름을 확인했습니다. 코드 품질은 플러터 애널라이즈(flutter analyze) 정적 분석으로 관리했습니다.
【ADR — 10초】
기술 의사결정 3건을 에이디알(ADR)로 기록했습니다. 플러터(Flutter)는 멀티플랫폼, 셋스테이트(setState)는 소규모 앱 단순성, 에스큐라이트(SQLite)는 오프라인 우선입니다.
